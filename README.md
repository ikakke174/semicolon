# Semicolon Technologies

Next.js + Tailwind CSS, structured like `asoebi-admin-ui`.

## Structure

```
src/
  app/                 # routes only
  module/
    view/              # page-level UI
    lib/
      components/      # shared components
      utility/         # hooks, services, store, types, paths
env/                   # environment config
```

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
